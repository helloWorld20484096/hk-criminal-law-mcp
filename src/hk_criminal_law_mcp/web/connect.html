Claude

Opens Claude's connector dialog with this server's name and URL filled in.

Add to Claude
If the button does not prefill
  1. Settings → Connectors → Add custom connector.
  2. Name: HK Criminal Law.
  3. URL: the address above, ending in /mcp.
  4. Choose OAuth and approve. On a public deployment this is automatic.
◎

ChatGPT

Opens the developer-mode connector form and copies the MCP URL for you.

Add to ChatGPT
Exact steps
  1. Enable Developer mode: Settings → Apps & Connectors → Advanced settings.
  2. Apps & Connectors → Create.
  3. Paste the copied URL into MCP Server URL.
  4. Choose OAuth. On an open deployment the authorization is automatic.
  5. Enable the connector in each chat from the + menu.

For a link your users can open in one click, publish a custom GPT with the core OpenAPI schema once and share the GPT link.

✦

Gemini

Opens Gemini's connected-apps screen and copies the MCP URL. Gemini has no public prefill link yet, so paste it into + Custom.

Open Gemini connectors
Exact steps and CLI fallback
  1. Settings → Connected Apps → Connectors → + Custom.
  2. Paste the URL, leave client ID/secret blank, choose Next.
  3. Complete OAuth and start a new chat. Type @ to select the app.

Gemini CLI: gemini mcp add --transport http hk-law …

⌁

DeepSeek Harness

One command installs the official MCP client plugin and adds this server to ~/.dsh/cordis.patch.yml.

View script 
curl -fsSL …/connect/dsh.sh | bash
What the script does

Installs @deepseek-ai/dsh-mcp-client into the web profile, backs up your config, and appends an mcp-hk-law server entry. Restart dsh web afterwards. Set DSH_PROFILE for another profile.
